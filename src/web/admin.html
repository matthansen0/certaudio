Claim admin access

No administrator has been registered yet. The bootstrap token is printed at the end of azd up. If you no longer have it, read it from the Function App settings: 

az functionapp config appsettings list -g <resource-group> -n <function-app> \
  --query "[?name=='ADMIN_BOOTSTRAP_TOKEN'].value | [0]" -o tsv

The token can only be claimed once, and it changes every time you provision.
